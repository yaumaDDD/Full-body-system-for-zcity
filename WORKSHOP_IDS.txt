Workshop ID для выделенного сервера ZCity
=========================================

Контент ZCity (уже прописан в lua/autorun/loader.lua как resource.AddWorkshop
при hg_loadcontent 1):

  3657897364   основной контент ZCity
  3257937532   distac content
  3389728250   Glide (машины/самолёты)
  3389795738   GTAV helicopters для Glide

C:U (Casualties: Source / Casualties: Unknown Health System):

  3728573930   сам аддон, ~41 МБ, живой обновляемый билд
  3440271589   Simple Custom Shaders — ОБЯЗАТЕЛЬНЫЙ Required item C:U

Отдельный C:U для запуска не обязателен: коннектор содержит 71 embedded C:U
Lua и 3 embedded WoundBridge Lua. Внешние Workshop/GitHub API приоритетны;
embedded загружается только при их отсутствии.

ВНИМАНИЕ: не ставьте два ВНЕШНИХ C:U одновременно — папкой из
casualites unknown.zip и подпиской 3728573930. Два external loader дадут
двойные хуки/таймеры/HUD/ошибки. Выберите максимум один внешний вариант.

UI-контент уже находится в коннекторе: 653 материала + 3 шрифта C:U +
3 собственных compiled .vcs. В full pack материалы также зеркалируются в
папку C:U, а fonts/shaders физически перенесены только в коннектор.
Коннектор сам регистрирует эти 659 paths для клиентов при
zc_woundsystem_compat_resource_downloads 1 (по умолчанию). Ради UI ничего
дополнительно перекидывать не нужно. Подписка 3728573930 может понадобиться
ради звуков C:U, а 3440271589 — только ради дополнительных внешних
Merc-эффектов; три собственных .vcs уже перенесены.

Подключение на выделенном сервере (один из способов):

  +host_workshop_collection <ID_коллекции> -authkey <ВАШ_STEAM_API_KEY>

Либо workshop.vdf в garrysmod/settings/ с ID коллекции. Клиенты получают
контент автоматически, вручную подписываться им не нужно.

Отдельно: zcitygore при установке папкой ищет свой ID через engine.GetAddons();
если не находит — задайте zcity_gore_torso_workshopid вручную.
