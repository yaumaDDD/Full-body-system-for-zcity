Workshop ID для выделенного сервера ZCity
=========================================

Контент ZCity (уже прописан в lua/autorun/loader.lua как resource.AddWorkshop
при hg_loadcontent 1):

  3657897364   основной контент ZCity
  3257937532   distac content
  3389728250   Glide (машины/самолёты)
  3389795738   GTAV helicopters для Glide

C:U (Casualties: Source / Casualties: Unknown Health System):

  3728573930   сам аддон, ~41 МБ, живой обновляемый билд
  3440271589   Simple Custom Shaders — ОБЯЗАТЕЛЬНЫЙ Required item C:U

ВНИМАНИЕ: не ставьте C:U одновременно папкой из casualites unknown.zip и
подпиской 3728573930. Это две копии Lua -> двойные хуки/таймеры/HUD/ошибки.
Выберите одно. Компат написан под билд из ZIP репозитория.

Материалы UI (647 файлов: casunknown-images/*, woundsystem/*, лимбы C:U,
кадры руки, .vtf/.vmt) уже лежат внутри сборки — в коннекторе и в папке C:U.
Ради них НЕ нужно ничего докачивать или перекидывать; подписка 3728573930
может понадобиться только ради звуков C:U и шейдеров 3440271589.

Подключение на выделенном сервере (один из способов):

  +host_workshop_collection <ID_коллекции> -authkey <ВАШ_STEAM_API_KEY>

Либо workshop.vdf в garrysmod/settings/ с ID коллекции. Клиенты получают
контент автоматически, вручную подписываться им не нужно.

Отдельно: zcitygore при установке папкой ищет свой ID через engine.GetAddons();
если не находит — задайте zcity_gore_torso_workshopid вручную.
